# Green Edge Lawn Care website

Static website (HTML and CSS, no build step) for Green Edge Lawn Care, a lawn care and landscaping service in Princeton, TX.

- Pages: Home, Services, Our Work, Contact, plus a 404 page.
- Photos: Green Edge Lawn Care's own work photos. Credits are in SOURCES.txt.
- Hosting: GitHub Pages from the main branch.

Live: https://rudsrudibotha.github.io/green-edge-lawn-care-preview/
